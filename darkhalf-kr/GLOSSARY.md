# 용어집 — 대사 번역 일관성 기준

세그먼트 1,239개를 배치로 나눠 번역하므로 표기가 흔들리기 쉽다. 그리고
**고유 음절 상한이 719자**라 표기를 통일하는 것이 곧 예산 절약이다.
새 용어를 정할 때는 이미 쓰는 음절을 재사용하는 쪽을 택한다.

## 문체

- 마왕 측: 예장체·하대 (「~하라」 「~느니라」 「~더냐」). 고압적으로.
- 용사 측: 평어 (「~다」 「~해」).
- 마을 사람: 존대 (「~요」 「~습니다」). 신분에 따라 조절.
- 병사·신하 → 마왕/왕족: 극존대 (「~옵니다」는 음절 낭비이므로 「~습니다」로 통일).

## 표기 규칙

- 문장부호는 게임 테이블의 전각을 쓴다: `！` `？` `。` `「` `」` `、` `‥`
  (ASCII 로 써도 `krcodec.ALIAS` 가 변환하지만 판독문과 맞추기 위해 전각으로 적는다)
- 말줄임은 `‥‥` (원문과 동일하게 2자)
- 개행은 `\n`. **원문의 개행 위치를 지킨다** — 게임 텍스트 창이 3줄이고
  줄 넘침을 렌더러가 처리하지 않는다
- `<XX>` 태그는 전부 그대로 보존한다. 단 `<魔>` `<士>` `<見>` `<入>` 네 개는
  제어 기능이 없는 한자 글리프이므로 버려도 된다 (바이트 절약)

## 음절 절약 요령

예산이 빡빡한 세그먼트에서 쓴다. 뜻이 흐려지면 쓰지 않는다.

| 대신 | 쓰기 | 절약 |
|---|---|---|
| ~하였습니다 | ~했습니다 | 1 |
| ~하고 있다 | ~한다 | 2 |
| ~할 수 없다 | ~못 한다 | 1 |
| ~하지 않으면 | ~않으면 | 2 |
| 그러나 | 하지만 → 그러나 (동일) | - |
| 당신들 | 그대들 / 너희 | 0~1 |
